# Changelog

Все значимые изменения в этом проекте документируются в этом файле.

## [Unreleased]

### Исправлено
- 🔒 Временный каталог сборки создаётся через `mktemp -d` вместо предсказуемого `/tmp/far2l-build-$$`
- 🧹 Временные файлы удаляются через `trap` и при ошибке сборки
- 🐛 Скрипт больше не завершается молча, если в `/etc/os-release` нет `VERSION_ID`
- 🛑 Понятная ошибка на системах без `apt-get`
- 📦 Пакет wxWidgets выбирается по наличию в репозиториях (исправлена установка на Mint, Pop!_OS, Ubuntu 20.04)
- 🤫 `apt` запускается с `DEBIAN_FRONTEND=noninteractive`

## [1.0.0] - 2026-05-14

### Добавлено
- 🆕 Автоматическое определение ОС через `/etc/os-release`
- 📦 Динамический выбор пакета `wxWidgets` (3.0 для Ubuntu 22.04, 3.2 для 24.04/Debian 12+)
- ⚡ Параллельная сборка с автоопределением количества ядер
- 🛡️ Строгий режим выполнения (`set -euo pipefail`) и проверка прав `root`
- 🧹 Автоматическая очистка `/tmp` после установки
- 🎨 Цветное логирование с разделением на INFO/WARN/ERROR

### Улучшено
- 🔒 Безопасное формирование массива зависимостей (защита от `unbound variable`)
- 📉 Оптимизация клонирования через `git clone --depth 1`
- 🔄 Идемпотентность: безопасный повторный запуск без конфликтов

### Известные ограничения
- Скрипт ориентирован на `apt`-репозитории. Для Arch/Fedora требуется адаптация.
- Путь установки по умолчанию: `/usr/local/bin`. Изменение требует правки `CMAKE_INSTALL_PREFIX`.
