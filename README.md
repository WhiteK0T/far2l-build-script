# far2l-installer

Автоматизированный bash-скрипт для сборки и установки `far2l` из исходного кода на Debian/Ubuntu-подобных системах.

## 🚀 Возможности
- ✅ Автоматическое определение версии ОС и дистрибутива
- 📦 Динамический выбор зависимостей (wxWidgets 3.0/3.2 в зависимости от версии)
- ⚡ Параллельная сборка с использованием всех ядер CPU
- 🛡️ Безопасное выполнение (`set -euo pipefail`, проверка прав root)
- 🧹 Автоматическая очистка временных файлов после установки
- 🎨 Цветной логирование для удобного отслеживания прогресса

## 🖥️ Поддерживаемые системы
| Дистрибутив | Версии |
|-------------|--------|
| Ubuntu      | 22.04 LTS, 24.04 LTS |
| Debian      | 12 (Bookworm), 13 (Trixie) |

> 💡 Скрипт использует пакет по умолчанию для неизвестных версий, но выводит предупреждение в лог.

## 📋 Требования
- Права `root` или `sudo`
- Стабильное интернет-соединение
- ~500 МБ свободного места на `/tmp` и `/usr/local`
- `bash 4.0+` (стандартно в современных дистрибутивах)

## 🛠️ Установка и запуск
```bash
# 1. Скачать скрипт
curl -fsSL https://raw.githubusercontent.com/WhiteK0T/far2l-installer/main/install_far2l.sh -o install_far2l.sh

# 2. Сделать исполняемым
chmod +x install_far2l.sh

# 3. Запустить от имени root
sudo ./install_far2l.sh
```

## ⚙️ Как это работает
1. Проверяет права `root` и включает строгий режим выполнения
2. Читает `/etc/os-release` для определения `ID` и `VERSION_ID`
3. Формирует список зависимостей, подставляя корректную версию `wxWidgets`
4. Обновляет `apt`, устанавливает пакеты, клонирует репозиторий `--depth 1`
5. Конфигурирует проект через `cmake`, собирает с `-j$(nproc)`
6. Устанавливает бинарник в `/usr/local/bin`, удаляет временные файлы

## 🎛️ Кастомизация
| Параметр | Как изменить |
|----------|--------------|
| Путь установки | Добавьте `-DCMAKE_INSTALL_PREFIX=/opt/far2l` в строку `cmake` |
| Отладочная сборка | Замените `Release` на `Debug` |
| Сохранить исходники | Закомментируйте строку `rm -rf "$BUILD_DIR"` |
| Включить verbose-лог | Добавьте `set -x` после `set -euo pipefail` |

## 🐛 Решение проблем
- **`apt: unable to locate package`** → Проверьте версию ОС. Для Ubuntu 22.04 скрипт автоматически подставит `libwxgtk3.0-gtk3-dev`. Если ошибка сохраняется, обновите репозитории вручную: `sudo apt update`
- **`cmake: not found`** → Убедитесь, что в системе установлен `build-essential` или `cmake`
- **Сборка прервалась** → Проверьте свободное место на диске и доступ к интернету. Повторный запуск безопасен.
